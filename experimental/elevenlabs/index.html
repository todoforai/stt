Voice Agent

A voice agent egy kommunikátor: a betöltött beszélgetés alapján először röviden összefoglalja a státuszt, majd részletez, és közben reagál a kérdéseidre — a választott nyelven. Nyomd meg a Start-ot és beszélj; bármikor közbevághatsz. Pipeline: helyi VAD → Scribe STT → LLM (Haiku 4.5, streamelt) → Piper TTS. Az A/B VAD-összehasonlító külön él: scribe-realtime.html.

System prompt (kommunikátor-szerep, angol) — {lang} és {conversation} behelyettesítve a Startkor

A nyelv ({lang}) a voice agent paramétere — a választó vezérli az STT-t és a beszéd nyelvét is.
